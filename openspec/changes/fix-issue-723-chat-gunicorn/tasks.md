- Each checkbox is ONE commit. Write the failing test, run it and see it fail, write the minimum code, run it green, then run `bash scripts/gate.sh` and commit. A task never ends red: the failing test and its fix go in the SAME commit. Put the red run (test names and the error) in the commit body.

- Commit messages: short, lowercase, no `Co-Authored-By` trailer. Use `git commit -F <file>` for a multi-line body. Never `--no-verify`.
- Do not edit `src/interfaces/chat_app/app.py`, any Dockerfile, `requirements/requirements-base.txt`, `tests/unit/test_telemetry.py`, or `_NON_BOOL_DEFAULT_BASELINE`.
