Gate before every commit: `bash scripts/gate.sh`, run **bare** — no pipe, no redirect (the

`git add`, not after: the pre-commit hook formats in place while CI only asserts, so a file

commit.

Each numbered task below is one loop turn and ends **green and committable** — the failing
test and the change that makes it pass are deliberately in the same task, because a turn

`requirements/cpu-requirementsHEADER.txt` or `requirements/gpu-requirementsHEADER.txt` (they
are the sources — changing a source to make a derived file match inverts the dependency);
editing `scripts/dev/build_docker_images.sh`; and touching `Containerfile`,
`.github/workflows/**`, `deploy/**`, `config/**`, `scripts/gate.sh` or `hooks/**`, which are
control-plane paths this automation must not modify. If you find yourself changing a pin,
stop — that is a different PR.
